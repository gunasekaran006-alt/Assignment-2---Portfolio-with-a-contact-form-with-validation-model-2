# Personal Portfolio Website 🚀

Welcome to my first professional web project! This is a **Static Portfolio Website** designed to showcase my journey as a Full Stack Developer.

## 🛠️ Tech Stack
- **HTML5**: Used for structured and semantic web content.
- **Form Handling**: Integrated a contact form for user interaction.

## 📂 Project Structure
- `index.html`: The home page with "About Me" information.
- `project.html`: A dedicated page showcasing my latest web projects.
- `contact.html`: A contact page with a form (Name, Email, Subject, Message).

## ✨ Key Features
- **Semantic HTML**: Optimized for better accessibility and SEO.
- **Clean Navigation**: Easy to switch between About, Projects, and Contact sections.
- **Form Validation**: Uses HTML5 attributes to ensure user data is entered correctly.

## 🚀 Future Enhancements
- Adding **CSS3** for a modern, responsive design.
- Implementing **JavaScript** for dynamic interactivity.
- Connecting the contact form to a backend using **Node.js & Express**.
